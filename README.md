# doodle-classifier
An interactive machine learning project that uses a convolutional neural network (CNN) to recognize hand-drawn doodles.

The model was trained using drawings from Google’s Quick, Draw! dataset across 10 categories:

Cat · Dog · Wine Bottle · Skateboard · Snake · Dumbbell · Shark · Guitar · Car · Palm Tree

The Jupyter Notebook in this repository contains the model development and training process, including data preparation, CNN architecture, training, evaluation, and testing.

The final model achieved 92.68% accuracy on a held-out test set of 20,000 drawings.

Try It

The trained model is deployed as an interactive doodle classifier on my portfolio. Draw directly in the browser and see what the neural network predicts.
